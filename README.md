# Синопсис
Меня задолбало окно UAC при открытии терминала, на пару с нейроговном был сделан скрипт .vbs и всякое другое дерьмо. Вся инструкция изложена здесь.
# Инструкция
### 1. Создание задачи в планировщике
   
Win+R, ```taskschd.msc```

Создать простую задачу

Внутри, следующие настройки

<img width="394" height="299" alt="image" src="https://github.com/user-attachments/assets/befac456-1401-480a-a40d-c5c75ba74880" />
   
В плашке "Действие" создать действие "Запуск программы", в качестве сценария использовать

```powershell
%LOCALAPPDATA%\Microsoft\WindowsApps\wt.exe
```

Не знаю насчет актуальности для 11й винды, у коротой "новый" терминал из коробки, возможно придется поменять путь к wt.exe
### 2. Скрипт .VBS

Имеется в репозитории, можно сделать вручную: создать .vbs, ПКМ по нему, изменить, вставить

```vbs
CreateObject("Wscript.Shell").Run "schtasks.exe /run /tn ""RunWTAdmin""", 0, False
```
### 3. Создание ярлыка

Все просто, достаточно кликнуть ПКМ по .vbs'ке, создать ярлык

Для доступа из пуска, поместить по пути %APPDATA%\Microsoft\Windows\Start Menu\Programs
